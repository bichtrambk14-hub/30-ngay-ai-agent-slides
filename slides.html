AI Agent

Tự động hóa công việc văn phòng: mỗi buổi 45 phút, mỗi buổi làm chủ một AI Agent.

4 tuần × 5 buổi (Thứ 2 – Thứ 6) · 12 AI Agent văn phòng · Dùng claude.ai và Claude Code

Khóa “30 Ngày Làm Chủ AI Agent” của CES Global dành cho nhân viên văn phòng, hành chính, nhân sự, kế toán, vận hành và quản lý. Ý chính: đừng chỉ hỏi AI, hãy giao việc cho AI Agent với đầu vào, đầu ra và cách kiểm tra rõ ràng.

Từ một trợ lý đến cả đội AI

MỨC 1 · Buổi 1–5

Trợ lý Project

Dùng trên claude.ai, không cần cài gì. Một trợ lý lo một việc.

MỨC 2 · Buổi 6–11

Artifact + Skill

Kỹ năng đóng gói sẵn, tự bật theo từ khóa. Cài Claude Code từ buổi 8.

MỨC 3 · Buổi 12–20

Đội trợ lý

Nhiều subagent phối hợp chạy trọn một quy trình, ghép thành Workspace cá nhân.

Cùng một tư duy xuyên suốt: giao việc có đầu vào – đầu ra – cách kiểm tra, chỉ khác công cụ.

Mức 1 là Project trên claude.ai, học 4 tính năng: Instructions, Context, Memory, Scheduled. Mức 2 là Skill trong Claude Code. Mức 3 là subagent và agent team, cuối khóa ghép thành Workspace cá nhân.

Workspace cá nhân

Mỗi agent chạy 3 bước: hỏi 4–6 câu ngữ cảnh → lập kế hoạch để bạn duyệt → làm rồi tự rà bảng kiểm.

Mỗi agent có hai file: AGENT.md là bản mô tả đầy đủ, SKILL.md là bản để cài vào Claude Code. Agent 12, Workspace cá nhân, là bộ điều phối: chọn đúng agent cho từng việc và nối chúng thành quy trình.

Cài vào Claude Code

1 Cài Node.js 18+ và Claude Code

npm install -g @anthropic-ai/claude-code

2 Đăng nhập và kiểm tra

Gõ claude để đăng nhập, rồi claude --version

3 Chép thư mục skill vào

C:\Users\<tên>\.claude\skills\

4 Gõ thử một yêu cầu

“Viết email xin nghỉ phép 2 ngày” → Claude hỏi lại 4–6 câu là cài đúng

Lưu ý: hướng dẫn nhắc thư mục Lo-trinh-30-ngay, nhưng repo này chỉ có 12 thư mục skill 01–12 trong thu-vien-agent-tham-chieu.

Cách tải bộ agent: Code → Download ZIP trên GitHub, hoặc git clone. Bộ công cụ phát cuối khóa (33 skill và 17 trợ lý) nằm ở repo riêng cesglobal-vn/ces-ai-agent-van-phong, nên lấy đúng bản v1.0.0. Buổi 12–20 vẫn đang được soạn.
